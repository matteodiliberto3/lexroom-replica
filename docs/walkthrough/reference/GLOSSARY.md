# Glossario

| Termine | Significato in questo repo |
|----------|----------------------------|
| **App Router** | Routing file-based in `app/` (Next 13+). |
| **Client Component** | File con `"use client"`; hooks e Motion qui. |
| **Spring** | Interpolazione “fisica” (Motion `useSpring`) vs easing lineare. |
| **Scroll-linked** | Valori animati da `useScroll` + `useTransform` al posto di keyframe manuali. |
| **Portal** | `createPortal` React: render figli in un nodo DOM esterno (es. `body`). |
| **Stacking context** | Ordine `z-index` influenzato da `transform`, `opacity`, `filter` sugli antenati. |
| **Bento** | Griglia asimmetrica di card feature. |
| **Reduced motion** | Preferenza OS utente; onorata in CSS e JS. |
| **CTA** | Call to action — qui spesso “Book a demo”. |
| **Parte A / Parte B** | Nel walkthrough: concetto stack/design vs file concreti nel clone. Vedi [Come funziona questo libro](../meta/how-the-book-works.md). |
